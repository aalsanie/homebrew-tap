# Distroplane Homebrew tap

This tap installs the Distroplane CLI and four bundled provider executables from verified, published release archives. Stable-release formula changes are proposed as pull requests; maintainers review them after macOS Apple Silicon, macOS Intel, and Linuxbrew install and audit checks.

Once a verified formula is merged, install with `brew install aalsanie/tap/distroplane`. The tap does not modify or delete per-project `.distroplane` plans, journals, or retained provider binaries.
